TEXTORA TECHNOLOGIES — BRAND ASSET KIT

CONTENTS

- Textora_Light_Background.png: green emblem + dark wordmark, transparent background; use on white/light surfaces.
- Textora_Primary.svg / Textora_Light_Background.svg: path-based SVG versions for scalable web/product placement.
- Textora_Primary_2x.png / Textora_Light_Background_2x.png: high-density raster exports.
- Textora_Monochrome_White.* and Textora_Monochrome_Dark.*: one-color variants for simple stamps, overlays, and low-color print use.
- Textora_Icon_Transparent.png / Textora_Icon.svg: standalone green emblem for app UI, favicon, sidebar, or product badge.
- Textora_Icon_White.png / Textora_Icon_White.svg: white standalone emblem for dark backgrounds.
- Textora_App_Icon_512.png / Textora_App_Icon.svg: square dark-background icon for Android/app branding; PNG sizes are also provided.
- Brand_Kit_Preview.jpg: quick reference sheet.

USAGE NOTES
- Use the SVG files for websites and responsive UI where scalable artwork is useful.
- Use the transparent PNGs when an SVG upload is not supported.
- Use the white-wordmark version on dark backgrounds and the dark-wordmark version on light backgrounds.
- App store / Play Store submissions may have their own current icon and safe-zone requirements; confirm those requirements before submission.
- The SVG files trace the supplied logo artwork into paths and simplify its green shading to a consistent brand green so they remain scalable. The transparent PNG assets preserve the supplied artwork's original colors and anti-aliasing.
